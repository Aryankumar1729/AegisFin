# AegisFin — Tableau & Power BI Dashboard Architecture Blueprint

**Platform:** AegisFin Commercial Banking Intelligence  
**Target Audience:** Commercial Banking C-Suite, Heads of Retail Lending, Product Strategy & Growth  

---

## 1. Overview & Architecture

The AegisFin Business Intelligence Suite consists of three interconnected, interactive executive dashboards engineered to translate complex banking transaction logs into commercial growth intelligence.

```
+-------------------------------------------------------------------------------+
|                       AEGISFIN ENTERPRISE DASHBOARD SUITE                     |
+----------------------------------------------------+--------------------------+
| 1. EXECUTIVE INTELLIGENCE & LIQUIDITY              | 2. BEHAVIORAL RFM STUDIO |
|    - Core Liquidity BAN Cards & Trajectory Trends  |    - 5x5 RFM Quintile Map|
|    - Monthly Active Transactors (MAT)              |    - Pareto Spend Curves |
|    - Metropolitan Volume Concentration             |    - Playbook Action Hub |
+----------------------------------------------------+--------------------------+
| 3. SPATIAL MARKET MATRICES & VELOCITY                                         |
|    - Metro Penetration Heatmap (Tier 1 vs Tier 2)                             |
|    - Demographic Spend Profiling (Age & Gender Clusters)                      |
|    - Account Balance Turnover & Velocity Dynamics                             |
+-------------------------------------------------------------------------------+
```

## 2. Global Dashboard Filters & Parameters

All three dashboards share a synchronized top-bar filter strip:

- **Date Range Picker:** Relative date slider (`2016-08-01` to `2016-10-31`).
- **Location Filter:** Multi-select dropdown (All, Mumbai, Bangalore, Delhi, Hyderabad, Pune, Kolkata, Chennai, etc.).
- **Customer Segment Filter:** Multi-select dropdown (Champions, Loyal Customers, Big Spenders, Potential Loyalists, At Risk, Dormant, Low Value).
- **Gender Filter:** Male, Female, Unknown.
- **Age Bracket Parameter:** All Ages, Young Adult (18-25), Early Career (26-35), Mid Career (36-50), Senior (51+).

## 3. Dashboard 1 — Executive Overview

**Primary Purpose:** High-level summary of transaction throughput, portfolio value, and customer engagement.

### Key Performance Indicators (Top BAN Cards)
1. **Total Customers:** `COUNTD([CustomerID])` | Format: `#,#` (e.g., `43,151`)
2. **Total Transactions:** `COUNT([TransactionID])` | Format: `#,#` (e.g., `100,000`)
3. **Total Transaction Value (INR):** `SUM([TransactionAmount])` | Format: `₹#,##0.00`
4. **Average Transaction Value:** `AVG([TransactionAmount])` | Format: `₹#,##0.00`
5. **Monthly Active Customers (MAC):** `COUNTD(IF [Month] = '2016-10' THEN [CustomerID] END)`
6. **Average Transactions / Customer:** `COUNT([TransactionID]) / COUNTD([CustomerID])`

### Visualizations & Chart Specs

#### Chart 1.1: Daily & Monthly Transaction Volume & Value Trend
- **Type:** Dual-Axis Line + Bar Chart
- **X-Axis:** `TransactionDate` (Day level / Month level)
- **Primary Y-Axis (Bars):** `SUM([TransactionAmount])` in Millions INR (Soft Teal)
- **Secondary Y-Axis (Line):** `COUNT([TransactionID])` (Navy Line with points)
- **Tooltips:** Date, Total INR Transacted, Total Transactions Count, Active Users.

#### Chart 1.2: Transaction Amount Size Distribution
- **Type:** Horizontal Stacked Bar Chart / Binned Histogram
- **Dimension:** Transaction Tier (`Micro < ₹500`, `Small ₹500-₹2k`, `Medium ₹2k-₹10k`, `Large ₹10k-₹50k`, `Very Large ₹50k+`)
- **Measure:** `% Share of Total Transactions` vs. `% Share of Monetary Volume`

#### Chart 1.3: Top 10 Indian Metro Cities by Banking Volume
- **Type:** Ranked Horizontal Bar Chart
- **Y-Axis:** `CustLocation`
- **X-Axis:** `SUM([TransactionAmount])` with color encoding by `COUNTD([CustomerID])`

## 4. Dashboard 2 — Customer Segmentation (RFM Analysis)

**Primary Purpose:** Segment customer base into actionable behavioral buckets based on Recency, Frequency, and Monetary value.

### Key Performance Indicators (Top BAN Cards)
1. **Champions Share:** `COUNTD(IF [CustomerSegment] = 'Champions' THEN [CustomerID] END) / COUNTD([CustomerID])`
2. **Loyal Customer Revenue Contribution:** `% of Total Spend generated by Loyal + Champions`
3. **At Risk Customer Count:** `COUNTD(IF [CustomerSegment] = 'At Risk' THEN [CustomerID] END)`
4. **Dormant Customer Value at Risk:** `SUM(IF [CustomerSegment] = 'Dormant / Lost' THEN [MonetaryValue] END)`

### Visualizations & Chart Specs

#### Chart 2.1: RFM 5x5 Quintile Matrix Heatmap
- **Type:** 2D Matrix Heatmap
- **Columns:** `R_Score` (1 to 5)
- **Rows:** `F_Score` (1 to 5)
- **Cell Size / Color:** `SUM([MonetaryValue])` and `COUNTD([CustomerID])`
- **Color Scale:** Sequential Navy-Teal gradient.

#### Chart 2.2: Customer Segment Distribution & Revenue Contribution
- **Type:** Side-by-Side Comparison Donut / Bar Charts
- **Left Chart:** Customer Count % per Segment
- **Right Chart:** Total Transaction Value % per Segment

#### Chart 2.3: Recency vs. Monetary Scatter Matrix
- **Type:** Scatter Plot
- **X-Axis:** `Recency (Days)`
- **Y-Axis:** `Monetary Value (INR)` (Log scale)
- **Color:** `CustomerSegment`
- **Size:** `Frequency`

---

## 5. Dashboard 3 — Geography & Transaction Behavior

**Primary Purpose:** Spatial density, city-level transaction metrics, and demographic behavior.

### Key Performance Indicators (Top BAN Cards)
1. **Top City Market Share:** Mumbai/Bangalore `% of Total Portfolio`
2. **Tier-1 Metro Average Ticket Size:** Average INR in metros vs. non-metros
3. **Median Customer Age:** Overall age profile (`31-42` years)
4. **Male vs. Female Spend Ratio:** Spend share comparison

### Visualizations & Chart Specs

#### Chart 3.1: Geographic Density Map of India
- **Type:** Symbol Map / Filled Regional Map
- **Latitude / Longitude:** Generated from `CustLocation`
- **Mark Size:** `COUNTD([CustomerID])`
- **Mark Color:** `AVG([TransactionAmount])`

#### Chart 3.2: Demographics Matrix (Age Bracket x Gender Spend)
- **Type:** Grouped Bar Chart
- **X-Axis:** Age Bracket (`18-25`, `26-35`, `36-50`, `51-65`, `65+`)
- **Y-Axis:** `AVG([TotalSpend])` split by `CustGender` (M vs F)

#### Chart 3.3: Customer Account Balance vs. Transaction Frequency
- **Type:** Scatter Plot / Bin Heatmap
- **X-Axis:** `CustAccountBalance`
- **Y-Axis:** `TxCount`

## 6. Calculated Fields (Tableau Syntax)

```tableau
// 1. Recency Days
DATEDIFF('day', [LastTransactionDate], #2016-11-01#)

// 2. Customer Segment Formula
IF [R_Score] >= 4 AND [F_Score] >= 4 AND [M_Score] >= 4 THEN "Champions"
ELSEIF [R_Score] >= 3 AND [F_Score] >= 3 AND [M_Score] >= 3 THEN "Loyal Customers"
ELSEIF [R_Score] >= 3 AND [M_Score] >= 4 THEN "Big Spenders"
ELSEIF [R_Score] >= 4 AND [F_Score] <= 2 THEN "Potential Loyalists"
ELSEIF [R_Score] <= 2 AND [F_Score] >= 3 THEN "At Risk"
ELSEIF [R_Score] <= 2 AND [F_Score] <= 2 AND [M_Score] <= 2 THEN "Dormant / Lost"
ELSE "Low Value / Casual"
END

// 3. Imputed Age Field
IF ISNULL([CustomerDOB]) OR YEAR([CustomerDOB]) = 1800 THEN 31
ELSE DATEDIFF('year', [CustomerDOB], #2016-11-01#)
END
```
